British Auction
RFQ System

A freight procurement platform where an administrator publishes a request for quotation and suppliers compete in a live auction. The system ranks bids, extends closing time when configured activity occurs, and records auction events for review.

How the auction works

  1. An administrator creates an RFQ, sets its schedule, and chooses the extension window (X), extension length (Y), and trigger rule.
  2. Suppliers submit an itemized quote, transit time, and validity date while bidding is open.
  3. Bids rank by lowest total price, then shortest transit time, then earliest submission.
  4. A configured trigger can extend the current closing time by Y minutes. The forced closing time is a hard limit.
  5. The system closes the auction and keeps an activity history. Admins see supplier identities; competitive supplier views mask competitors.

Features

Admin portal

Create and schedule RFQs, manage supplier accounts and platform settings, monitor live auctions, and review the audit history.

Supplier portal

Register, browse RFQs, submit quotes, follow rank updates, and review dashboard and bid history.

Auction rules

Supports bid received, any-rank-change, and leading-bid-change triggers, with a strict forced-close limit.

Live updates

WebSocket events deliver auction changes to authenticated clients with role-aware visibility.

Scheduled lifecycle

A background scheduler activates RFQs at their start time and closes auctions at the deadline.

Persistence

SQLAlchemy models store users, RFQs, auction configuration, bids, settings, and activity logs.

Run locally

Run each part in a separate terminal from the project root.

1. Backend

cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 3000 --reload

To restore sample data from the project root:

backend/venv/bin/python backend/seed.py

2. Admin application

cd admin-frontend
npm install
npm run dev

Open http://localhost:5173. Seeded account: admin@rfq.com / admin123.

3. Supplier application

cd supplier-frontend
npm install
npm run dev

Open http://localhost:5174. Seeded account: supplier1@test.com / supplier123; suppliers can also register from the site.
