Design

Six relational tables support user access, RFQ configuration, supplier quotes, runtime settings, and an auditable auction history.

Ranking ruleQuotes are ordered by total price ascending, then transit days ascending, then first submitted. The same ordering drives L1 and trigger evaluations.

3. Data integrity notes

Calculated quote total

The API derives total_amount as freight_charges + origin_charges + destination_charges. Clients do not choose the stored total independently.

Auction deadline invariant

Create and update paths reject forced_bid_close_time ≤ bid_close_time. Extensions use min(current close + Y, forced close).

Database behavior

SQLAlchemy models declare String/Float/Integer/Boolean/DateTime types. SQLite is the default runtime database. No migration framework or explicit bid-ranking composite index is currently present.
